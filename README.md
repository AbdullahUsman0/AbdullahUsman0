I'm a CS student at **FAST-NUCES, Pakistan**, and I turn AI research into working software — retrieval pipelines, fine-tuned language models, and agents that call real tools. Underneath it all: C++ fundamentals, because fast and correct code still matters.

Most recently I built **[ParityLens](https://github.com/AbdullahUsman0/parity-check)** — a bilingual exam-parity auditor — for the Alibaba Cloud AI Hackathon Pakistan 2026.
