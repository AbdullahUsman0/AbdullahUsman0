I'm a CS student at **FAST-NUCES, Pakistan**, and I turn AI research into working software — retrieval pipelines, fine-tuned language models, and agents that call real tools. Underneath it all: C++ fundamentals, because fast and correct code still matters.

Most recently I built **[ParityLens](https://github.com/AbdullahUsman0/parity-check)** — a bilingual exam-parity auditor — for the Alibaba Cloud AI Hackathon Pakistan 2026.

---

### What I Work On

| Area | Focus |
| --- | --- |
| **AI / NLP** | Transformers, RAG pipelines, multilingual NER, summarization, Whisper speech input, local SLM fine-tuning (llama.cpp) |
| **Agents** | OpenAI + n8n + MCP tool orchestration — agents that book meetings, write records, and route approvals |
| **Full-Stack** | React, Node.js, Next.js, TypeScript, MySQL, WebSockets |
| **Systems** | C++ data structures & algorithms, OOP design, 8086 assembly |
| **Mobile** | Kotlin (Android), React Native |

### Featured Projects

| Project | What It Does | Stack |
| --- | --- | --- |
| [RAHATAI](https://github.com/AbdullahUsman0/RAHATAI-multilingual-crisis-response) | Multilingual crisis-response NLP platform — crisis classification (Transformer, SVM, LSTM, CNN), multilingual NER, BART summarization, misinformation detection, and RAG Q&A over official docs, with Whisper voice input | Python, PyTorch |
| [ParityLens](https://github.com/AbdullahUsman0/parity-check) | Independent QA gate that catches meaning drift between Urdu and English exam papers before they print — hybrid rules + semantic engine, human reviewer queue, PDF QA reports | Python, Streamlit |
| [ClientOps AI](https://github.com/AbdullahUsman0/ClientOps-AI) | MCP-powered agent that turns a plain-English client request into scheduled meetings, client records, approvals, and notifications in one shot | OpenAI, n8n, MCP |
| [SkillSwap](https://github.com/AbdullahUsman0/SkillSwap) | Peer-to-peer skill-exchange platform — real-time listings, profiles, and chat without money changing hands | React, Node.js, MySQL |
| [CrisisConnect](https://github.com/AbdullahUsman0/CrisisConnect) | Real-time disaster alert app with location-based alerts and voice-activated chat | Kotlin |
| [ConnectPlus](https://github.com/AbdullahUsman0/ConnectPlus) | A social network built from scratch in C++ — users, pages, posts, timelines, custom memory management | C++ |
